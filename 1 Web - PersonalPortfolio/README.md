# Personal Portfolio

My personal portfolio website, built with **Flask** and **Jinja2**.

It showcases my projects, technical skills, experience, and other information about me as a developer.

## Technologies

- Python
- Flask
- Jinja2
- HTML5
- CSS3
- JavaScript
- uv

## Features

- Personal introduction and profile
- Projects showcase
- Technical skills
- Responsive design
- Server-side rendering with Jinja2

## Getting Started

### Prerequisites

- Python 3.x
- uv

### Installation

Clone the repository:

    git clone <repository-url>
    cd <repository-directory>

Install the dependencies:

    uv sync

Run the application:

    uv run python app.py

Then open http://localhost:5000 in your browser.
